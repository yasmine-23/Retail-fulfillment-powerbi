# Retail Fulfillment & Customer Experience Analytics

**Status:** Planned

This project explores where delivery delays occur in the Olist marketplace
and whether late deliveries are associated with lower customer review scores.

The Power BI report will cover sales performance and fulfillment quality,
with breakdowns by seller, product category, and region. Order-level metrics
will count each order once, including orders with multiple items.

**Stack:** Power BI Desktop, Power Query, DAX  
**Data:** [Olist Brazilian E-Commerce Dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)  
**Deliverables:** Power BI report, star schema, KPI definitions, and key findings.
